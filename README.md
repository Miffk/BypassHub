# BypassHub

Программа для Windows, которая объединяет в одном окне
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (обход блокировок Discord, YouTube и др.)
и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (ускорение Telegram Desktop).

- Переключатели вкл/выкл, значок в трее, горячие клавиши
- Все настройки zapret и tg-ws-proxy в одном месте, автоподбор стратегии zapret
- Индикаторы доступности Discord / YouTube / Telegram
- Автоматическое обновление zapret, tg-ws-proxy и самой программы
- Тёмная и светлая темы, свои цвета: всё окно окрашивается градиентом, как темы в Discord

## Скачать

Откройте **[Releases](../../releases/latest)** и скачайте `BypassHub.exe`. Программа попросит права
администратора (они нужны zapret) и при первом запуске сама скачает zapret и tg-ws-proxy.

Подробное описание, сборка из исходников и выпуск новых версий — в [BypassHub/README.md](BypassHub/README.md).

Сами zapret и tg-ws-proxy принадлежат их авторам (Flowseal, bol-van); BypassHub скачивает только их официальные релизы.
